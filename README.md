# Authenticity AI

AI-powered Telegram bot for detecting counterfeit and suspicious products on Ozon.

## Features
- Real-time product risk analysis
- Advanced risk scoring system
- Analysis history (saved to JSON)
- Beautiful Telegram interface
- Fully modular OOP architecture

## Technologies
- Python 3
- Aiogram 3
- OOP + Decorators
- File I/O + JSON
- Regex parsing

## How to run
1. `pip install -r requirements.txt`
2. Create `.env` with your bot token
3. `python bot.py`
